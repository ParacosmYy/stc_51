# 基于 STC89C52 的 SPWM 波形发生器

> 1Hz~20Hz 可调 SPWM 波形输出，模块化软件架构，适合课程设计与实验验证。

## ✨ 项目亮点

- **1Hz~20Hz** 频率可调, 按键增减
- `P3.7` 输出 SPWM 波形，便于示波器观察或后级驱动
- 两位共阳数码管实时显示当前频率
- **显示刷新不走中断**，全部在主循环中完成
- 结构清晰、模块化拆分，便于扩展

## 🧱 硬件架构

### 核心器件

- MCU：STC89C52
- 晶振：11.0592 MHz
- 显示：两位共阳数码管
- 按键：频率加/减
- 输出：SPWM 波形（接示波器或后级驱动）

### 系统框图

```text
     ┌──────────┐    按键(P3.2/P3.3)     ┌──────────────┐
     │  供电/晶振 │ ───────────────────▶ │  STC89C52   │ ──▶ SPWM(P3.7)
     └──────────┘                         │              │
                                         │              │ ──▶ 数码管显示(P1/P2)
                                         └──────────────┘
```

### 引脚分配

| 单片机引脚 | 功能 | 说明 |
|-----------|------|------|
| P1.0~P1.6 | 七段数码管 a~g 段 | 段选，低电平点亮 |
| P2.0 | 数码管十位位选 | 低电平选中十位 |
| P2.1 | 数码管个位位选 | 低电平选中个位 |
| P3.2 | 频率减按键 | 低电平有效 |
| P3.3 | 频率加按键 | 低电平有效 |
| P3.7 | SPWM 输出 | 接示波器或后级驱动 |

> 若数码管位序相反，请检查 `DIG_TENS` 与 `DIG_ONES` 接线。

## 🧩 软件架构

### 模块分层

```text
Core       : main.c / STARTUP.A51 / config.h
Application: app.c / app.h
Drivers    : display.c / key.c
Modules    : spwm.c / freq.c / tick.c
```

### 主流程与节拍

- `main.c` 仅负责初始化与主循环
- 主循环中持续调用 `app_task()` 进行任务调度
- `Timer0`：专用于 SPWM 输出
- `Timer1`：仅用于产生按键扫描节拍
- 数码管刷新 **只在前台 `while (1)` 中完成**

### 设计约束

1. `Timer0` 仅用于 SPWM 输出
2. `Timer1` 仅用于产生按键扫描节拍
3. 数码管扫描不在中断中执行
4. 主循环持续调用 `display_task()` 刷新数码管

## 🛠️ 编译与下载

1. 使用 **Keil uVision** 打开 `test.uvproj`
2. 确认晶振参数为 **11.0592MHz**
3. 编译生成 `HEX`
4. 下载到 STC89C52 单片机
