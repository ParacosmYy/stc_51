# stc_51

> 建议后续重命名为 `GS_Embedded_51`：51 单片机实验与课程项目合集。

当前项目是一个基于 **STC89C52** 的 SPWM 波形发生器，支持 1Hz 到 20Hz 频率调节，并通过两位共阳数码管显示当前频率。

## 项目定位

| 项目 | 说明 |
|------|------|
| MCU | STC89C52 |
| 晶振 | 11.0592 MHz |
| 输出 | `P3.7` 输出 SPWM 波形 |
| 输入 | 按键调节频率 |
| 显示 | 两位共阳数码管 |
| 工程用途 | 课程设计、51 裸机实验、模块化代码练习 |

## 功能特性

- 1Hz 到 20Hz SPWM 输出；
- 按键增加/减少频率；
- 数码管实时显示当前频率；
- Timer0 专用于 SPWM 输出；
- Timer1 专用于按键扫描节拍；
- 数码管刷新放在主循环，不在中断中做重活；
- 按应用层、驱动层、功能模块拆分代码。

## 软件分层

```text
Core        : main.c / STARTUP.A51 / config.h
Application : app.c / app.h
Drivers     : display.c / key.c
Modules     : spwm.c / freq.c / tick.c
Documents   : 设计文档与说明
```

## 硬件连接

| 引脚 | 功能 | 说明 |
|------|------|------|
| `P1.0~P1.6` | 数码管段选 | 低电平点亮 |
| `P2.0` | 十位位选 | 低电平选中 |
| `P2.1` | 个位位选 | 低电平选中 |
| `P3.2` | 频率减少按键 | 低电平有效 |
| `P3.3` | 频率增加按键 | 低电平有效 |
| `P3.7` | SPWM 输出 | 接示波器或后级驱动 |

## 编译与下载

1. 使用 Keil uVision 打开 `test.uvproj`；
2. 确认晶振参数为 11.0592MHz；
3. 编译生成 HEX；
4. 下载到 STC89C52；
5. 使用示波器观察 `P3.7` 输出波形。
